# Data Structures in C++

> Classic data structures implemented from scratch in C++: stack, simple queue, circular queue and linked list.

![C++](https://img.shields.io/badge/C%2B%2B-00599C?logo=cplusplus&logoColor=white)
![Visual Studio](https://img.shields.io/badge/Visual%20Studio-5C2D91?logo=visualstudio&logoColor=white)

## What's inside

| Structure | Operations |
| --- | --- |
| **Stack** (array) | push, pop, peek, display, overflow and underflow checks |
| **Simple queue** (array) | enqueue, dequeue, display, full and empty checks |
| **Circular queue** (array) | enqueue and dequeue with wrap-around, display |
| **Linked list** (nodes) | insert, insert after a position, delete by value or position, search by value or index, display |

All structures are written by hand without the STL, to show how they work inside. The code is in `full project/Source.cpp`.

## Use it

The file holds the structure definitions and their operations (it has no `main()`). To try them, open `full project.sln` in Visual Studio, or add `Source.cpp` to any C++ project, then create the structures and call their functions from your own `main()`.
